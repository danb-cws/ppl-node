# PPL Node

PPL is an offline-first, privacy-focused radio device for discovering nearby people and exchanging direct encrypted messages through a mesh network.

## Project goals

- Local discovery without a central platform
- Direct, encrypted messaging
- Reticulum-compatible networking
- Standalone operation using the device screen and physical controls
- Optional local Wi-Fi web interface
- Finite, privacy-friendly device storage
- Simple, approachable user experience

## Current status

Greenfield project — initial planning and hardware experimentation.
